## 🚀 시작하기

### 요구사항

- Python 3.10+
- Discord Bot Token
- Google Gemini API Key

### 설치

```bash
# 의존성 설치
pip install -r requirements.txt

# 최신 버전으로 의존성 업데이트
pip install -U -r requirements.txt
```

### 실행

```bash
python main.py
```

### 왜 이렇게 나눴나

처음에는 `main.py` 하나(약 1,100줄)에 명령어, Cog 클래스, 투표 UI가 모두 들어 있었습니다. 기능이 늘수록 한 파일에서 찾고 고치기 어려워져 역할별로 나눴습니다.

| 나눈 곳 | 맡은 일 | 이렇게 하면 |
|---------|---------|-------------|
| `cogs/` | 기능(투표·공략·챗봇·공지)마다 파일 하나 | 한 기능을 고칠 때 그 파일만 열면 됩니다 |
| `ui/` | 투표 Select·View | 명령어 처리와 화면 부품이 섞이지 않습니다 |
| `utils/` | 날짜 변환·검증, 투표율 막대 | 디스코드 없이도 따로 확인할 수 있는 순수 함수입니다 |
| `bot/` | 봇 생성, Cog 로드, 스케줄러 | `main.py`는 실행만 합니다 (35줄) |
| `boss_data.json` | 보스 13종 정보와 이미지 경로 | 보스 정보가 코드 밖에 있어 공략 내용을 코드 수정 없이 고칠 수 있습니다 |

## ⚙️ 환경변수 설정

프로젝트 루트에 `.env` 파일을 생성하세요:

```bash
# 필수 설정
DISCORD_TOKEN=<Discord Bot Token>
GEMINI_API_KEY=<Google Gemini API Key>
CHANNEL_ID=<공지사항 전송 채널 ID>

# 개발 모드 (선택)
DEV_MODE=true                    # true로 설정 시 개발 모드 활성화
TEST_CHANNEL_ID=<테스트 채널 ID>  # 개발 모드에서 사용할 채널
```

| 변수명 | 필수 | 설명 |
|--------|:----:|------|
| `DISCORD_TOKEN` | ✅ | Discord 봇 토큰 |
| `GEMINI_API_KEY` | ✅ | Google Gemini API 키 |
| `CHANNEL_ID` | ✅ | 자동 공지사항 전송 채널 ID |
| `DEV_MODE` | ❌ | `true` 설정 시 테스트 채널 사용 |
| `TEST_CHANNEL_ID` | ❌ | 개발 모드 시 사용할 채널 ID |

### 📊 투표

| 명령어 | 설명 |
|--------|------|
| `/단일투표 "[제목]" [날짜...]` | 단일 선택 투표 생성 (투표 변경 가능) |
| `/중복투표 "[제목]" [날짜...]` | 다중 선택 투표 생성 (여러 날짜 동시 선택) |
| `/투표목록` | 현재 진행 중인 투표 목록 |
| `/투표종료 [제목]` | 투표 종료 및 결과 표시 |

**예시:**
```
/단일투표 "이번 주 레이드" 2024-12-20 2024-12-21 2024-12-22
/중복투표 "가능한 날짜" 2024-12-20 2024-12-21
/투표종료 이번 주 레이드
```

> 📝 **참고**: 날짜는 `YYYY-MM-DD` 형식, 최대 5개까지 입력 가능

## 📅 자동 작업

### 자동 공지사항 전송

- **실행 시간**: 매주 수요일 오전 10시 05분
- **대상 채널**: `.env`의 `CHANNEL_ID` (개발 모드 시 `TEST_CHANNEL_ID`)
- **내용**: 로스트아크 공지사항 링크 + 배너 이미지

> APScheduler를 사용하여 비동기 스케줄링됩니다.

## 🆕 새 보스 추가하기

### 1단계: 보스 데이터 추가

`boss_data.json`에 새 보스 정보를 추가하세요:

```json
{
  "보스이름": {
    "name": "보스이름",
    "aliases": ["보스이름", "별칭"],
    "description": "보스 설명",
    "color": "blue",
    "difficulties": ["노말", "하드"],
    "image_path": "images/카테고리/보스폴더",
    "gate_count": {
      "노말": 2,
      "하드": 2
    },
    "difficulty_stars": {
      "노말": "⭐⭐☆☆☆",
      "하드": "⭐⭐⭐☆☆"
    }
  }
}
```

### 2단계: 이미지 추가

이미지 폴더 구조:
```
images/{category}/{boss_name}/
├── normal/
│   ├── 1gate.png
│   └── 2gate.png
└── hard/
    ├── 1gate.png
    └── 2gate.png
```

### 3단계: 명령어 추가

`cogs/boss_strategy.py`에 서브커맨드를 추가하세요:

```python
@boss.command(name='보스이름', aliases=['별칭'])
async def new_boss(self, ctx: commands.Context, difficulty: Optional[str] = None):
    """보스이름 공략"""
    await self._handle_boss_command(ctx, '보스이름', difficulty)
```
